4. 我们不处理的信息

  • 不要求注册，不收集手机号、邮箱、身份证号、地址。
  • 不读取与预算编制无关的文件；读写只发生在用户通过系统对话框选择的路径与本软件自己的状态文件。
  • 不采集设备指纹、MAC、IMEI、广告标识符；授权版机器码只在本机用于校验。
  • 不接入广告、统计、推送、崩溃收集 SDK。

5. 第三方共享

不向任何第三方提供、出售或共享用户数据。软件没有服务端，开发者无法从软件获得任何用户数据。

6. 内嵌组件：Microsoft Edge WebView2

本软件使用 Microsoft Edge WebView2 运行时显示界面。该组件由 Microsoft 提供，其自身的数据处理适用 Microsoft 的隐私声明，不适用本政策：

  • Microsoft 隐私声明：https://privacy.microsoft.com/zh-cn/privacystatement
  • WebView2 运行时说明：https://learn.microsoft.com/microsoft-edge/webview2/

边界说明：我们收集的——无，软件只加载随包本地页面（http://127.0.0.1:51362/… 回环地址）；组件自身的——WebView2 可能在本机维护缓存、Cookie 存储与组件更新数据，按其自身机制与 Microsoft 交互，不包含本软件写入的业务数据。

7. 保存位置与期限

全部数据保存在用户本机，不跨境传输。卸载会删除安装目录与 WebView2 用户数据目录。从 1.4.12 起，MSIX 版的窗口状态写在包容器 %LOCALAPPDATA%\Packages\<包族名>\LocalState\ 内，随卸载删除；免安装版的同一文件在 %LOCALAPPDATA%\工程勘察设计预算软件\，通常不涉及“卸载”，需要时手动删除即可。

8. 如何删除数据

  1. 工程/导出文件：在资源管理器中删除。
  2. 窗口状态：MSIX 版在 %LOCALAPPDATA%\Packages\<包族名>\LocalState\window_state.json；免安装版在 %LOCALAPPDATA%\工程勘察设计预算软件\window_state.json。
  3. 内嵌浏览器数据：关闭软件后删除 %APPDATA%\KcsjBudget.exe\EBWebView。
  4. 授权信息（仅授权版）：在软件内清除授权，或删除上述站点数据。
  5. 彻底移除：在“设置 → 应用”中卸载，MSIX 版无需再手动清理本软件数据。

9. 未成年人

本软件是面向工程预算编制人员的专业工具，不面向未成年人设计，也不收集年龄信息。未成年人使用应在监护人指导下进行。

10. 政策更新

本政策随软件版本更新。新增联网功能、新增数据收集或新增第三方组件时，会在新版本发布时同步更新本文，并在商店“此版本中的新增功能”中说明；重大变更同时在软件内“关于”页提示。
