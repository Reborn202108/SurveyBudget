Privacy Policy

Geotechnical Investigation & Design Budgeting Software · Version 1.4.11 (Windows desktop / Microsoft Store) · Effective: 2026-11-19

E0. Summary

This application makes no outbound network requests and does not collect or upload any personal information. There is no account system, login, remote configuration, update check, telemetry, or crash reporting, and no remote fonts or CDN references. License validation (licensed edition) is performed entirely on the local machine.

E4. Information we do not process

  • No registration; no phone numbers, email addresses, ID numbers, or addresses collected.
  • No files unrelated to budgeting are read; access occurs only at paths chosen by the user and the app's own state file.
  • No device fingerprints, MAC addresses, IMEI, or advertising identifiers; the machine code in the licensed edition is used locally only.
  • No advertising, analytics, push, or crash-reporting SDK.

E5. Third-party sharing

We do not provide, sell, or share user data with any third party. The application has no backend; the developer cannot obtain user data from it.

E6. Embedded component: Microsoft Edge WebView2

The application uses the Microsoft Edge WebView2 runtime to render its UI. The component is provided by Microsoft, and its own data handling is governed by Microsoft's privacy statement, not by this policy:

  • Microsoft Privacy Statement: https://privacy.microsoft.com/privacystatement
  • WebView2 documentation: https://learn.microsoft.com/microsoft-edge/webview2/

Collected by us: none — the app never passes a remote URL to WebView2, only packaged local pages over http://127.0.0.1:51362/…. Handled by the component: WebView2 may maintain local cache, cookie storage, and component update data, and may interact with Microsoft under its own mechanisms; this contains none of the app's business data.

E7. Storage location and retention

All data stays on the user's machine; nothing crosses borders. Uninstalling removes the install directory and the WebView2 user data directory. Since 1.4.12, the MSIX build keeps window state inside the package container (%LOCALAPPDATA%\Packages\<family name>\LocalState\), which is removed on uninstall; the portable build keeps using %LOCALAPPDATA%\工程勘察设计预算软件\ and can be deleted manually.

E8. How to delete your data

  1. Project/export files: delete them in File Explorer.
  2. Window state: MSIX build — %LOCALAPPDATA%\Packages\<family name>\LocalState\window_state.json; portable build — %LOCALAPPDATA%\工程勘察设计预算软件\window_state.json.
  3. Embedded browser data: close the app, then delete %APPDATA%\KcsjBudget.exe\EBWebView.
  4. License data: clear the license in the app, or delete the site data above.
  5. Full removal: uninstall via Settings → Apps, then clean the leftover in E7.

E9. Children

This is a professional tool for budgeting practitioners. It is not designed for children and does not collect age information. Use by a minor should be supervised by a guardian.

E10. Changes to this policy

This policy is updated with software releases. If a release adds network functionality, data collection, or a third-party component, this document is updated at release time and noted in the Store "What's new in this version" field; material changes are also flagged on the in-app About page.
